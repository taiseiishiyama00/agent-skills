# 実装対応表

## `ITTAN-VISUAL-010` の実装・実証

要求の正本は [`output-rules.md`](output-rules.md) の `ITTAN-VISUAL-010`。機械可読の対応は [`.implementation-map.json`](.implementation-map.json) に置く。以下の実装パスとコマンドの起点は `youtube-remotion-renderer` リポジトリ。

| 紐づけ | 実装・実証手段 |
|---|---|
| 正式アバターの登録 | `assets/blender/ittan-seiri/registry.json`。素材ID、正式blendの相対パスとSHA-256、共通出力先を対応させる |
| 進行君・通常 | `host` → `assets/blender/ittan-seiri/host-audio-reactive-rig.blend` |
| 進行君・疑問 | `host-question` → `assets/blender/ittan-seiri/host-question-audio-reactive-rig.blend` |
| 進行君・驚き | `host-surprised` → `assets/blender/ittan-seiri/host-surprised-audio-reactive-rig.blend` |
| 解説さん | `explainer` → `assets/blender/ittan-seiri/explainer-audio-reactive-rig.blend`。独立した正式リグのない表情指定も、このリグを参照する |
| 共通素材の生成 | `npm run avatar:shared:build` → `scripts/build-ittan-avatars.mjs` → `scripts/blender-avatar/render-approved-loop.py`。正式blendを開いて4口形の連番を生成する |
| 全作品の素材参照 | `src/channels/ittan-seiri/branding/avatars.ts`。`public/assets/channels/ittan-seiri/blender-avatars/<素材ID>/` を共通キャッシュとし、作品内へ複製しない |
| 動画への組み込み | `src/channels/ittan-seiri/branding/BlenderCast.tsx`、`src/formats/conversation-explainer/components/ContinuousAvatarRig.tsx`、`blender-avatar.ts`。Blender連番を再生する。静止画用途は同じ連番の閉口先頭フレームを参照する |
| リグ構造の検証 | 各正式blendに `blender --background --python-exit-code 1 <正式blend> --python scripts/blender-avatar/ittan-seiri-host/validate_avatar.py` を実行する。テクスチャ内包、口・頭・毛先等の構造と動作を検査する |
| 素材の実証 | `npm run avatar:verify` → `scripts/verify-ittan-avatars.mjs`。要求本文のハッシュ、正式blendのハッシュ、生成コードのハッシュ、全連番のハッシュ、旧素材と旧参照の不存在を検査する |
| 再利用・口形選択の検証 | `npx vitest run tests/blender-avatar-contract.test.ts tests/avatar-verification.test.mjs` |
| 証拠 | `tmp/verification/ITTAN-VISUAL-010.json`。要求・対応表・実装・各リグ・生成manifestのハッシュと成否を記録する。各素材の `provenance.json` に全連番のハッシュとBlender版を記録する |

`ITTAN-AUDIO-004` の完成動画における音声同期は別の実証対象。上記の口形選択テストだけで同期済みとは判定しない。`BlenderCast` は作品の音声振幅を受け取る。音声振幅を渡していない既存の `ContinuousAvatarRig` 利用箇所は閉口で再生されるため、音声同期の実証対象として残る。
