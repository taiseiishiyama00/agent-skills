# 観点表

mini-sdd のフェーズ 1 で、FR が十分かを判定する観点の正本である。使うたびに育てていく部分であり、追記の手順は SKILL.md の「観点表を育てる」に従う。

| 機能の種別 | 観点 |
|---|---|
| 画面の表示（一覧、詳細、検索） | 応答性（待ち時間、読み込み中の表示）、0 件や大量のとき、並び順と絞り込み、権限による見え方の違い |
| 入力と登録、更新、削除 | 入力の検証とエラーの見せ方、誤操作の防止と取り消し、二重送信、同時に更新されたとき、完了の知らせ方 |
| 通知、メール | 届くタイミング、送る相手と条件、送れなかったとき、止める方法 |
| バッチ、非同期処理 | 実行のタイミング、進み具合の見え方、失敗したときの再実行、処理中の画面の扱い |
| API、外部連携 | 応答性とタイムアウト、相手が止まっているとき、呼び出し側へのエラーの返し方、互換性 |
| ファイルの入出力 | 形式と文字コード、サイズの上限、壊れたファイル、途中で失敗したとき |
| 認証、権限 | 誰が何をできるか、権限がないときの見せ方、ログインが切れたとき |
