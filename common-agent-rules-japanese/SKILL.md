# エージェント共通ルール（日本語）

## 言語

- スキル、ドキュメント、設計メモ、README、仕様書など、人が読む説明文は原則として日本語で書く。
- コード、API 名、識別子、コマンド、ログ、エラーメッセージ、外部仕様で英語が必要な箇所は原文または英語表記を維持する。
- ユーザーが明示的に別言語を指定した場合は、その指定を優先する。

## 対話の回答

- 成果物作成ではなく、対話の回答については、原則として 1000 文字以内にする。
- 考えながら回答するのではなく、一度回答案を生成し、内容の妥当性と上記制約を満たすことを確認してから回答する。
