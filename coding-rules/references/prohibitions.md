# 禁止事項

このファイルは、実装スキル（[mini-sdd](../../mini-sdd/SKILL.md)）とレビュースキル（[pr-review](../../pr-review/SKILL.md)）が共有して参照するコーディングルール（主に禁止事項）の正本である。
使うたびに新しい禁止事項を追加して育てていく部分であり、追記の手順は [../SKILL.md](../SKILL.md) の「禁止事項を育てる」に従う。

## テストと本番コードの境界

- **テストのためだけの本番実装を入れない**: テスト専用インターフェース、テスト用コンストラクター、テスト用 DI 登録、`InternalsVisibleTo` などのテストのためだけの実装・抽象化を本番コードへ導入してはならない（テスト側で Fake を作る。それができないなら本番側の `static` 依存自体を見直す）。
