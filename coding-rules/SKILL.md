# 共通コーディングルール

## 目的

実装スキル（`mini-sdd`）とレビュースキル（`pr-review`）が同じ基準で設計・実装・レビューできるよう、守るべきルールを共有する。

## ルール本体

主に禁止事項だけを [references/prohibitions.md](references/prohibitions.md) にまとめる。網羅的なスタイルガイドや「こう書くとよい」という一般論は書かず、やってはいけないことだけを端的に残す。

## 禁止事項を育てる

実装やレビューの中で、共有すべき新しい禁止事項が採用されたら、次の手順で追記する。

1. **追記するとき**: 利用者から共有コーディングルールとして採用の指示があったとき。
2. **追記する場所**: [references/prohibitions.md](references/prohibitions.md) の該当カテゴリの末尾に追記する。該当カテゴリがなければ新しく作る。
3. **反映のしかた**: この `SKILL.md` がある Git リポジトリの既定ブランチを `git pull --ff-only` で最新化し、`coding-rules/references/prohibitions.md` だけをコミットして `git push` する。作業中のリポジトリのブランチには含めない。
4. **反映できないとき**: リポジトリでない、未コミットの変更がある、push が拒否されたなどの場合は、追記する内容を利用者に報告して作業を続ける。
