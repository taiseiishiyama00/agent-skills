# 共通コーディングルール

このファイルは、実装スキル（[mini-sdd](../../mini-sdd/SKILL.md)）とレビュースキル（[pr-review](../../pr-review/SKILL.md)）が共有して参照するコーディングルールの正本である。
使うたびに新しいルールを追加して育てていく部分であり、追記の手順は [../SKILL.md](../SKILL.md) の「コーディングルールを育てる」に従う。

## テストと本番コードの境界

- **テストのためだけの本番実装を入れない**: テストのためだけの抽象化（テスト専用インターフェース、テスト用コンストラクター、DI 登録、`InternalsVisibleTo` 等）を本番コードへ導入しない。テスト側で Fake を作り、それができないなら本番側の `static` 依存自体を見直す。
